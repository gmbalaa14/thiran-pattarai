# Exploration Agents

Launch 2–3 **Explore** agents in parallel (subagent_type: `Explore`).

## Agent 1 — Impact Analysis

Identify:

* Entry points
* API endpoints
* Services
* Domain models
* Persistence layers
* Configuration involved

## Agent 2 — Pattern Discovery

Identify existing implementations that can be reused:

* DI registrations
* Logging patterns
* Validation patterns
* Error handling
* Background services
* Repository patterns

## Agent 3 — Testing & Infrastructure

Identify:

* Unit tests
* Integration tests
* Test fixtures
* CI/CD dependencies
* Infrastructure impacts
